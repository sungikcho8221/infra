Kubernetes 클러스터 구축 및 네트워크·서비스 운영

개발·운영 Kubernetes 환경의 클러스터 구성과 워크로드 운영을 담당했습니다. CNI와 BGP 기반 서비스 네트워크를 검증하고, LoadBalancer·Ingress·서비스 메시 등 클러스터 네트워크 경로를 구성·점검했습니다. 단순 설치에 그치지 않고 외부 네트워크 장비와의 연동, 서비스 접근 경로, 클라이언트 IP 전달 여부까지 확인했습니다.

KubernetescontainerdCiliumCalicoIstioHarbor
$ kubectl describe — 세부 수행 내용
클러스터 네트워크 설계 및 전환 검토
  • Calico 기반 환경에서 MetalLB·OpenELB를 이용한 BGP 동적 라우팅을 비교 테스트하고, 게이트웨이와 클러스터의 AS 구성 및 BGP 피어링을 검증
  • Calico와 MetalLB BGP 구성 시 발생한 포트·프로토콜 충돌을 분석하고, UTM 장비와 BGP 피어링 중 발생한 미지원 capability 관련 오류를 조사
  • CNI를 Calico에서 Cilium으로 전환 테스트하고 BGP Peer 및 LoadBalancer IP Pool 구성
  • Cilium의 eBPF·DSR 설정과 SNAT masquerade 비활성화를 조합해 외부 클라이언트 원본 IP가 애플리케이션까지 전달되는지 확인
플랫폼 운영
  • 개발·운영 클러스터 구성 및 분리, 노드 추가·제거와 클러스터 재구축
  • Istio Gateway, Harbor 등 클러스터 내 공통 플랫폼 구성 및 서비스 연결 확인
  • 운영 환경의 DNS·인증서 설정과 컨테이너 이미지 다운로드 경로 점검
검증 결과

네트워크 구성 변경 후 애플리케이션에서 실제 클라이언트 IP가 확인되는 것까지 검증하고, 구성 차이와 트러블슈팅 내용을 문서화했습니다.

LDAP 서비스 컨테이너화 및 복제 구성 자동화

LDAP 서버의 설치·초기화 절차를 컨테이너 이미지와 시작 스크립트로 표준화했습니다. Kubernetes StatefulSet의 안정적인 Pod 식별 특성을 활용해 복제 구성을 설계하고, 초기화·복제 절차를 자동화했습니다. 배포 이후에는 복제 상태와 인증 연동 문제를 로그 및 네트워크 설정을 기준으로 분석했습니다.

OpenLDAPDockerKubernetesStatefulSetShell
$ kubectl describe — 세부 수행 내용
컨테이너 이미지 및 초기 구성
  • Ubuntu 기반 Docker 이미지에 LDAP 설치 및 초기 설정 스크립트를 포함하고, 환경변수로 서버 설정을 전달해 컨테이너 시작 시 자동 구성되도록 구현
  • 단일 LDAP 구성과 복제 구성을 구분할 수 있도록 서버 수 등의 환경변수 기반 초기화 흐름 설계
Kubernetes StatefulSet 기반 복제
  • Pod IP가 재생성 시 변경되는 문제를 확인하고 Deployment 대신 고정된 네트워크 식별자를 제공하는 StatefulSet 방식으로 변경
  • 서비스 DNS를 이용해 ldap-0, ldap-1 형태의 Pod 간 통신을 구성
  • 설정된 서버 수와 포트 연결 여부를 확인한 뒤 LDAP dsreplication의 enable·initialize 절차를 자동 실행하도록 스크립트 구현
  • 마지막으로 생성된 LDAP 인스턴스에서 복제 초기화가 수행되도록 실행 조건 구성
운영 및 장애 분석
  • LDAP Replication 상태, 웹 콘솔 표시 상태, 서버 간 통신 및 인증 연동 문제 점검
  • 복제 과정의 Server ID 오류와 네트워크 프록시 개입 가능성 등 원인을 로그와 구성 관점에서 분석

About Me.

운영 경험을 바탕으로 인프라를 설계하고 개선합니다.

Linux 서버 운영을 기반으로 가상화·컨테이너 플랫폼, Kubernetes 클러스터, 네트워크 및 인증 인프라를 구축·운영해 왔습니다. 서비스 요구사항에 맞춰 인프라 구성 요소를 연결하고, 배포·운영 과정에서 발생하는 문제를 로그와 설정, 네트워크 흐름을 따라 분석합니다.

반복되는 작업은 Bash·Python·Ansible·CI/CD로 자동화하고, 운영 과정에서 필요한 자산 관리 플랫폼과 API도 개발했습니다. 인프라 운영과 플랫폼 개발을 함께 이해하며 안정성, 재현성, 유지보수성을 개선하는 엔지니어를 지향합니다.
